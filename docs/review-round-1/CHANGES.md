### Бэкенд: что изменилось в данных и API

- Миграция `016-route-endorsement.sql`: `approval_step.kind` (`APPROVAL`/`ENDORSEMENT`); у «Другого документа» и у
  юриста и бухгалтера демо-записки обязательность снята.
- Отправка принимает явный маршрут `{ stages, endorser }`; прежний формат `selections` поддерживается.
- Новые поля: `displayStatus` (списки, карточка), `recognizedKind` (списки), `type.code` (карточка), `previous`
  (предпросмотр маршрута), `previousRoles` (заявки). Новые запросы: `GET /documents?q=`, `DELETE /documents/{id}`,
  `PATCH /orgs/current/routes/{typeId}/roles/{roleId}`. Всё — в [API_CONTRACTS.md](../API_CONTRACTS.md).

### А. Ссылки и бот (LNK-1, LNK-2, LNK-3, LNK-4) — Булат и Илья, два живых аккаунта

Нужны: аккаунт **А** — администратор реальной компании; аккаунт **Б** — не состоит ни в какой компании. Каждую
строку матрицы пройти на **Android** и в **web.max.ru**; перед строкой «без чата» — удалить чат с ботом у Б.

| Состояние Б | Общая ссылка (код) | Личная ссылка |
|---|---|---|
| Чата с ботом нет | шаги 1–3 | шаги 4–5 |
| Чат с ботом есть | шаги 1–3 | шаги 4–5 |
| Мини-приложение уже открыто | шаги 1–3 | шаги 4–5 |

1. **А:** «Компания» → «Пригласить сотрудников» → «Поделиться» → отправить ссылку Б в личные сообщения.
2. **Б:** нажать ссылку. Ожидается: открывается мини-приложение и сразу экран **«Заявка отправлена»**. Если открылся
   чат с ботом — бот должен прислать кнопку; нажать её → тот же экран. Если открылось приветствие «Согласование
   документов» — **ошибка**: записать, в какой строке матрицы, и прислать скриншот.
3. **А:** пришло сообщение бота о заявке с кнопкой **«Открыть заявки»** → нажать → экран «Заявки» с заявкой Б
   (LNK-4). Отклонить (чтобы повторить строку).
4. **А:** «Пригласить сотрудников» → «Создать личную ссылку» → отметить роль «Юрист» → «Создать» → «Поделиться» → Б.
5. **Б:** нажать ссылку → экран «Приглашение» с компанией и ролью → «Вступить» → главная компании. **А:** пришло
   сообщение о вступлении. Затем А: «Участники и роли» → Б → «Исключить из компании» → «Исключить» (для следующей
   строки).
6. **LNK-2.** А и Б в одной компании, у Б открыто мини-приложение на главной. А отправляет документ, где Б —
   согласующий. **Б:** в чате бота «…ждёт вашего решения…» → «Открыть документ». Ожидается: карточка этого
   документа, а не главная и не другой раздел. То же — при закрытом приложении.
7. **LNK-3.** **Б:** написать боту часть названия, которая есть у двух документов компании. Ожидается: список и
   кнопка «Показать все» → экран «Поиск документов» с тем же запросом. Одно совпадение → «Открыть документ» →
   карточка.
8. Если что-то не так — в web.max.ru открыть консоль браузера (F12) и прислать строки `[approval]`: там видно, дошёл
   ли параметр запуска до моста и до сервера.

### Б. Вёрстка в MAX (LAY-1, LAY-3, DOC-2, чек-лист §6) — Никита на Android, Матвей в web.max.ru

Открыть бота → «Открыть мини-приложение» → «Посмотреть демонстрацию» (или «Продолжить демонстрацию»). На каждом шаге
ожидается: страница целиком **не прокручивается** (двигается только середина), нижние кнопки видны целиком, подписи не
обрезаны многоточием.

1. Главная: четыре плитки и «Новый документ» — без прокрутки. Плашка «Демо · вы действуете как…» — не прижата к
   верху и не уходит под шапку MAX (LAY-3).
2. «Новый документ» → нажать зону «Выберите файл документа» → выбрать фото из галереи → красная зона «Фото не
   подходит…». «Выберите другой файл» → `01_memo_ok.docx` из «Избранного» → карточка файла → «?» в углу зоны →
   панель «Какие файлы подходят» → закрыть.
3. «Далее: проверить документ» → экран проверки, шаг 2 из 3 → «Далее: выбрать согласующих» → конструктор, шаг 3.
4. «Отправить на согласование» → карточка. Плашка «Демо» → выбрать «Демо Юрист» → «На моём согласовании» → документ.
   Внизу: «Согласовать» на всю ширину, ниже «Вернуть на доработку» и «Отклонить» — целиком, без обрезки (DOC-2).
5. Повторить шаг 2 с `.doc`: на карточке файла — строка «Для этого файла автоматическая проверка недоступна…»; после
   загрузки поля вводятся вручную.

### В. Перетаскивание в конструкторе (RTE-2) — Никита на Android
